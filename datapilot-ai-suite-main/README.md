# DataPilot AI

Build a world-class SaaS web application called "DataPilot AI".

Purpose:

DataPilot AI is an AI-powered data science copilot that helps users upload datasets, automatically clean data, perform exploratory data analysis, train machine learning models, generate business insights, and chat with their data.

Design Goal:

The product should feel like a funded startup product, not a student project.
